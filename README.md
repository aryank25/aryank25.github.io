# 👨‍💻 Aryan Kumar — Personal Portfolio

---

## ✨ About

This repository contains the source code for my personal portfolio website.

The website is designed to provide an overview of my journey as an **Electronics & Telecommunication Engineering student at RV College of Engineering**, along with my work in software development, embedded systems, IoT, and other technical projects.

It also serves as a central place to showcase my projects, experience, skills, and achievements.

---

## 🚀 Features

- 🎨 Clean and responsive portfolio design
- 📱 Fully responsive across desktop, tablet, and mobile
- 👨‍💻 About Me section
- 🛠️ Technical skills and technologies
- 💻 Projects showcase
- 📄 Resume section
- 🏆 Achievements and extracurricular activities
- 💼 Internship & experience section
