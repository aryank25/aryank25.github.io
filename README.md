# Aryan Kumar — Tania-inspired portfolio

Static HTML/CSS/JS portfolio inspired by the structure and interaction model of Tania Rascia's digital-garden site. Content is based on Aryan Kumar's supplied resume.

## Run locally

Open `index.html`, or use VS Code + Live Server.

## Files

- `index.html` — portfolio content
- `styles.css` — responsive design + six palettes
- `script.js` — light/dark mode + palette persistence
- `aryan_resume.pdf` — supplied resume, linked from the site

## Palette options

New Moon, Ocean, Forest, Rose, Amber, Indigo.

The selected palette and light/dark preference are stored in localStorage.
